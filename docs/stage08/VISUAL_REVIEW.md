# Визуальная приёмка: 21 экран макета

Дата обновления: 2026-11-06. **Полное визуальное соответствие — BLOCKED.** Просмотрены исторические normal/AX5 снимки CI9/CI10 на iPhone SE и iPad mini и новые CI15 снимки на iPhone26/iPad26. Текущий кандидат, завершённые и незавершённые проверки перечислены в [TEST_REPORT.md](TEST_REPORT.md). Полный CI15 (`55bfcfb`), targeted regression CI16 (`a33a153`) и deletion-only CI17 (`163fb79`) имеют разный объём: результаты одного scope не объявляются полной native приёмкой другого.

Это сводка исходной design matrix, существующих нативных снимков и уже выполненных визуальных review. Здесь не выполнено новое попиксельное сравнение всех экранов и не созданы недостающие изображения. Статус PARTIAL в таблице означает наличие конкретного структурного/типографического evidence, а не визуальный PASS экрана целиком.

Просмотрен normal/AX5 набор полного CI15 на обеих iOS26 платформах: [iPhone26, 26 PNG](ACCESSIBILITY_CI15_IPHONE26_REVIEW.md), [iPad26, 26 PNG](ACCESSIBILITY_CI15_IPAD26_REVIEW.md). На каждой платформе Core AX завершил 49 проходов без retry; сохранены 22 raw findings на iPhone26 и 16 на iPad26, все reviewed. Core AX, AX5 и Settings прошли, но каждый suite — **FAIL, 34 PASS / 1 FAIL из 35**, из-за deletion helper: [iPhone receipt](evidence/ci-attempt15/iPhone26-receipt.json), [iPad receipt](evidence/ci-attempt15/iPad26-receipt.json). CI16 iPad26 повторил Core: 49 completed, 0 retry, 15 reviewed raw findings; targeted suite — **FAIL, 13/14**, deletion ([receipt](evidence/ci-attempt16/iPad26-receipt.json)). CI16 iPhone26 завершил targeted suite **14 PASS / 0 FAIL / 0 SKIP из 14**, в том числе deletion; Core — 49 completed, 0 retry, 22 reviewed raw findings ([receipt](evidence/ci16-iphone26-regression/receipt.json)). Эти targeted результаты не являются 35-case full suite или новым полным visual review. Core-код и product layout не менялись при переходе к `163fb79`; этот кандидат меняет только deletion keyboard helper/workflow. Эти факты не закрывают visual parity всех 21 DESIGN ID.

CI16 iPhone26 дополнительно сохранил четыре снимка удаления: initial, retry, presubmit и success. Retry показывает полный текст ошибки неверного пароля, пустое поле и disabled submit; success — login выбранного сервера с «Аккаунт удалён на сервере.». Отдельного confirmation-alert PNG нет: cancel/confirm подтверждены assertions успешного теста, не визуальным просмотром alert. Имя keyboard-снимка не доказывает видимую клавиатуру: `app.screenshot()` здесь её не захватил. Это ограниченное evidence удаления, не visual PASS всех его состояний.

## Типографика, цвета и осознанные iOS-адаптации

Inter-Regular/SemiBold действительно встроены из аудированного Android source; [font resource manifest](../ios/evidence/stage02/resource-manifest.json) и OFL снимают прежний Stage 1 вопрос о наличии native TTF. [MSTheme](../../Packages/MeetSpaceKit/Sources/DesignSystem/Theme.swift) использует `Font.custom(...relativeTo:)`, а не фиксированный bitmap текста. Наличие масштабируемого API само по себе не доказывает отсутствие clipping: конкретные hosted measurements и их границы приведены в accessibility reviews выше. Web px/line-height и iOS points/text metrics не объявляются одинаковыми.

В Stage 8 намеренно усилены **light-theme semantic colors** относительно исходного workspace CSS/Stage 7:

| Semantic color | Прежнее значение | Stage 8 |
| --- | --- | --- |
| muted | `#727687` | `#686c7d` |
| accent | `#6264d9` | `#5d5fcd` |
| success | `#25836c` | `#237962` |
| danger | `#d14857` | `#c03d4c` |

Это изменения для читаемости, а не утверждение о точном копировании цветов DESIGN. Background/surface/ink и соответствующие dark semantic значения сохранены. [Численная проверка контраста](evidence/contrast.json) относится к foreground/background из исходников; она не заменяет проверку compositing, disabled opacity, системных controls или фактически перекрытого текста на PNG. Не следует объявлять все raw contrast findings ложными на основании одного semantic ratio.

Другие адаптации: SF Symbols вместо web icons; native navigation, SecureField, menus, date picker, sheets и alert; Inter typography с Dynamic Type; горизонтальная прокрутка дней; compact settings navigation при AX-размере; native AVPlayer. Календарные month/list и backend-limited recordings filters не имеют точной пары в web. Формы прав/ошибок основаны на фактическом API, даже если demo показывает больше действий. CI9 и последующий CI10 подтвердили исправленные AX5 Messages heading/scroll и recording cards на компактном SE и iPad mini; CI10 добавил отдельно просмотренные normal-size состояния. Последующие CI15 reviews добавили реальные normal/AX5 состояния обеих iOS26 платформ. Полнота конкретных текстов не доказывает все layout/alert состояния; непроверенные device/runtime states не наследуют этот visual результат. Текущий native gate — [TEST_REPORT.md](TEST_REPORT.md).

## Что необходимо для закрытия visual gate

1. Использовать уже сохранённые [CI15 iPhone26](ACCESSIBILITY_CI15_IPHONE26_REVIEW.md) и [CI15 iPad26](ACCESSIBILITY_CI15_IPAD26_REVIEW.md) reviews: по 26 оригинальных normal/AX5/reveal/Settings PNG, с source/device/runtime и hashes. Исторические CI9/CI10 reviews сохраняют компактные SE/iPad mini состояния и подтверждение исправления двух CI7 layout P2. Эти наборы не закрывают внутренние формы Settings при AX5, нижние controls профиля, открытый диалог/keyboard, все confirmation/error/loading состояния и всю матрицу 21 DESIGN ID. Дополнять evidence по этим конкретным пробелам; текущий результат deletion-only CI17 и оставшихся CI15/CI16 jobs брать из [TEST_REPORT.md](TEST_REPORT.md).
2. Для всех реализованных экранов добавить недостающие состояния из таблицы: loading/empty/error/offline/reconnecting/session-expired, permissions, upload/download, keyboard и все длинные строки. Исходный DESIGN не содержит полного нативного набора; визуальные решения должны быть явно согласованы, а не объявлены идентичными отсутствующему макету.
3. Проверить portrait/landscape, iPad Split View/multiwindow, iOS/iPadOS 18 и актуальную ОС, светлую/тёмную темы, все нужные Dynamic Type категории и ручной VoiceOver. Отдельные старые dark/large-text снимки не закрывают текущие live screens. Физические CallKit/ReplayKit/camera permissions требуют устройств.
4. Шесть SSH screens оставить BLOCKED до реализации действительного installer flow. AI/transcript/message reactions, не имеющие действительного контракта, не добавлять ради сходства с demo.

Итог этой матрицы: инвентаризированы **21/21 DESIGN ID**, для существующих снимков даны проверяемые пути и происхождение. Это полнота учёта экранов, **не 21/21 визуально принятых экранов**. Полная pixel parity и окончательная visual acceptance этапа 8 не заявляются.
