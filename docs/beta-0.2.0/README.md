Apple — версия `0.2.0`, сборка `2`, одинаковые у приложения и ReplayKit extension.

## Установщик

Из welcome открывается мастер установки сервера: адрес VPS и домен, проверка
SHA-256 отпечатка SSH до передачи credentials, пароль или OpenSSH ключ,
диагностика, параметры, план, обязательный администратор, подтверждение
Docker/Let's Encrypt и изменений, установка и восстановление наблюдения.
Пароли и приватные ключи используются в памяти; сохраняются публичный ключ
сервера и публичный ticket задания. Изменившийся ключ блокирует подключение.

Установка использует подписанный runner Android; оригинальные файлы и
[provenance](../../Packages/MeetSpaceKit/Sources/Installer/Resources/provenance.json)
сохранены в пакете. Серверы пользователя этой работой не устанавливались.
Собственный SSL-сертификат показан в прототипе, но текущий Android runner его
не поддерживает: рабочий сценарий выпускает сертификат Let's Encrypt.

## Чаты

Доступны системное «Поделиться», копирование, ответ, пересылка с сохранением
авторства, закрепление, выделение нескольких сообщений и удаление выбранных.
Как в Android, массовое удаление скрывает сообщения **на этом устройстве**;
у других участников они остаются. Отдельное удаление собственного сообщения
выполняется на сервере. Диалог подтверждения объясняет разницу.

Локальные скрытые UUID хранятся атомарно с изоляцией server/account, исключены
из резервной копии и учитываются в истории, поиске и превью ответов. При ошибке
записи сообщения и выделение сохраняются. Подтверждённое удаление аккаунта
очищает этот локальный список. Обычный logout сохраняет его.

На iOS системное меню «Поделиться» открывается отдельной панелью: действия
доступны и на iPad с iOS 18, где привязанный к нижней кнопке popover обрезался.
Текстовое «Поделиться» содержит текст и имена вложений; сам файл можно передать
после его авторизованного скачивания через действие «Сохранить или поделиться».
Пересылка внутри MeetSpace использует настоящий API, включая вложения; старому
серверу без этого endpoint требуется обновление.

## Аудио

Раздел повторяет структуру шаблона: микрофон, динамик, звонки и уведомления;
на телефоне controls расположены вертикально, на планшете — в строку.
Проверка микрофона запрашивает разрешение по нажатию и показывает реальный уровень,
проверка динамика воспроизводит короткий сигнал. Запись не сохраняется.
Проверки останавливаются при закрытии экрана, фоне, прерывании и начале звонка.

Выбор входа и усиление зависят от реального оборудования; неподдерживаемое
усиление недоступно. Для громкости и выходов используются системные controls iOS.
Громкость системных звонков/уведомлений задаётся в iOS, а не имитируется отдельным
ползунком приложения. Настройки входа, шумоподавления и выключенного микрофона
применяются при следующем подключении к конференции.

В Simulator на Mac системный `MPVolumeView` не предоставляет регулировку громкости.
Вместо пустого места показан недоступный для изменения ползунок с фактическим
`AVAudioSession.outputVolume` и пояснением. На физическом iPhone или iPad используется
настоящий системный регулятор громкости.

Simulator ZIP содержит `arm64` и `x86_64` для Xcode Simulator на Mac с Apple Silicon или Intel.
Архитектуры приложения, WebRTC и ReplayKit extension, а также подписи simulator
bundle проверяются перед упаковкой. После распаковки откройте
Xcode → Open Developer Tool → Simulator, загрузите симулятор iPhone/iPad и
перетащите `MeetSpace.app` в его окно. Для входа укажите адрес своего сервера.
Фикстуры доступны только в Debug UI-тестах: опубликованный Release использует
настоящий API и SSH. Проверки новой установки проводите на предназначенном для
MeetSpace VPS после сверки SSH-отпечатка и просмотра плана изменений. Device ZIP содержит
неподписанный `.xcarchive`: для установки на iPhone нужен экспорт с собственной
Apple-подписью. IPA/TestFlight без подписи не заявлены.

Исторические отчёты этапа 8 описывают прежние исходники и сохраняются без
переписывания результатов. Полная проверка реального VPS, внешней доставки APNs,
камеры и ReplayKit на физических устройствах остаётся отдельной приёмкой.
